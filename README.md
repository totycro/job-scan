# job-scan

An LLM-based tool to help check job postings

This is a command line tool, that takes links to a job posting as an input and digests it based on my custom criteria.

It includes typical aspects such as a match about what the role would be like, what the company does, if the technology is interesting to me, what the job satisfaction rates on respective platforms are, etc.
It can also check commute times (if it's not remote).

In this early iteration, it's not clear yet how the workflow will be for managing the outputs over the course of a job search.
